# Original replacement illustrations

Seven self-authored SVG illustrations replace media with insufficient asset-specific provenance. No external images, fonts, logos, or copied artwork are embedded. They deliberately change the visuals and must not be counted as exact upstream media reproduction. `mapping.json` lists every substitution.

The recycling video replacement is a static SVG, not a video. The runtime must choose an image fallback. All other assets retain their enclosing animation and crop behavior.
